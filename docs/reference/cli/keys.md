# `liquid keys`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid keys <show|rewrap|rotate|revoke|split> ...
```

## Description

Inspect, rotate, revoke, rewrap, or split data-key custody material.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--to` | `<custody-uri>` | Rewrap a data key for this custody URI. | none |
| `--threshold` | `<count>` | Set the number of shares required to recover a key. | none |
| `--shares` | `<count>` | Set the number of custody shares to create. | none |

## Availability

available

## Examples

```sh
liquid keys show
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
