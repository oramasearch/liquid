# `liquid gc`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid gc [--dry-run] [--json] [--explain] [--compact] [--compact-below <fraction>] [repository]
```

## Description

Checkpoint reachable roots, collect unreachable objects, and optionally compact packs.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--dry-run` | — | Report collection without removing data. | false |
| `--json` | — | Write stable JSON instead of text. | false |
| `--explain` | — | Explain the roots retaining live objects. | false |
| `--compact` | — | Compact eligible packs after collection. | false |
| `--compact-below` | `<fraction>` | Compact packs below this live-byte fraction. | implementation default |

## Availability

available

## Examples

```sh
liquid gc --dry-run --explain .
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
