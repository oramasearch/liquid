# `liquid session`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid session <start <delegation>|write <id> <path> --from <file>|publish <id> [--message <text>]|discard <id>>
```

## Description

Start, write, publish, or discard a delegated private repository session.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--from` | `<file>` | Read session-write content from this file. | required for write |
| `--message` | `<text>` | Record this message when publishing a session. | empty |

## Availability

available

## Examples

```sh
liquid session publish <session-id> --message "ready for review"
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
