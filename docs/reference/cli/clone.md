# `liquid clone`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid clone <url|drive-folder> [<dir>] [--json]
```

## Description

Create a repository from a sync endpoint or configured drive folder, persist its remote, and materialize every file.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--json` | — | Write stable JSON instead of text. | false |

## Availability

available

## Examples

```sh
liquid clone https://lake.example.invalid/repositories/example ./example --json
```

## Exit status

0 on success, 1 when authorization, repository lookup, target validation, or transfer fails, and 2 for invalid usage.
