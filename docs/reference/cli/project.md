# `liquid project`

## Synopsis

```text
liquid project <oci|ostree|bootc|deb|rpm|apk|helm|macos-pkg|macos-dmg|msix|winget|homebrew|pkgbuild|appimage|flatpak|snap|dsc> <result|change|tree|installer> [--overlay [path=]<tree>] [--ref <name>] [--mode <archive-z2|bare-user>] [--name <name>] [--version <version>] [--arch <arch>] [--out <dir>] [--depends <dependency>] [--against <path>] [--replaces <package>] [--service <value>] [--identifier <id>] [--publisher <subject>] [--display-name <name>] [--executable <path>] [--entitlements <path>] [--installer-url <url>] [--distribution <suite>] [--compat-gzip] [--allow-abi-break] [--json]
```

## Description

Project a recorded result, change, tree, or installer into a package, source package, image, Helm chart, OSTree commit, or bundled-runtime artifact. Changes and trees resolve in the current repository without build configuration; result IDs also resolve in its build repository. Use liquid tree to obtain the recorded root digest. Installer paths are accepted only by winget. Debian source input requires a recorded change, result, or install tree with a producing result; a change needs one declared build target or recorded build evidence. Overlay trees must belong to the primary source repository.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--name` | `<name>` | Set the projected artifact name. | liquid-os for OS targets |
| `--version` | `<version>` | Set the projected artifact version. | commit epoch for OS targets |
| `--arch` | `<arch>` | Set the target architecture. | source architecture |
| `--out` | `<dir>` | Write projected artifacts below this directory. | projection |
| `--depends` | `<dependency>` | Declare a package dependency; repeatable. | none |
| `--against` | `<path>` | Check file ownership against packages or an installed database. | none |
| `--replaces` | `<package>` | Permit owned paths by deriving replacement relationships. | none |
| `--service` | `<value>` | Add a Helm service declaration; repeatable. | none |
| `--identifier` | `<id>` | Set the platform package identifier. | derived from name |
| `--publisher` | `<subject>` | Set the MSIX certificate subject. | development subject |
| `--display-name` | `<name>` | Set the platform display name. | package name |
| `--executable` | `<path>` | Set the packaged application executable. | derived from name |
| `--entitlements` | `<path>` | Record macOS signing entitlements. | none |
| `--installer-url` | `<url>` | Set the winget installer URL. | required for winget |
| `--ref` | `<name>` | Set the OSTree ref. | required for OS targets |
| `--overlay` | `[path=]<tree>` | Overlay a tree at an optional relative path; repeatable. | none |
| `--mode` | `<archive-z2\|bare-user>` | Select the OSTree repository mode. | archive-z2 |
| `--distribution` | `<suite>` | Set the Debian source distribution. | unstable |
| `--compat-gzip` | — | Use gzip-compatible package compression. | false |
| `--allow-abi-break` | — | Permit an incompatible ABI projection. | false |
| `--json` | — | Write stable JSON instead of text. | false |
