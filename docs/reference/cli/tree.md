# `liquid tree`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid tree
```

## Description

Print the current recorded root tree digest, including its algorithm prefix. This reads repository state without importing unrecorded filesystem edits. The output can be passed directly to project.
