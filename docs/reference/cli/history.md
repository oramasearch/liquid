# `liquid history`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid history <path> [--restore <change>]
```

## Description

Show the changes affecting a path or restore its content from a selected change.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--restore` | `<change>` | Restore the path from the named change. | none |

## Availability

available

## Examples

```sh
liquid history notes.txt
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
