# `liquid compact`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid compact --epoch [--min-ack-peers <count>]
```

## Description

Checkpoint current document heads and optionally wait for peer acknowledgements.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--epoch` | — | Checkpoint the repository's current epoch. | required |
| `--min-ack-peers` | `<count>` | Require this many peer acknowledgements. | 0 |

## Availability

available

## Examples

```sh
liquid compact --epoch --min-ack-peers 2
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
