# `liquid mount`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid mount <mountpoint> [--read-only]
```

## Description

Mount the repository working tree and hydrate content when it is read.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--read-only` | — | Deny writes through the mounted working tree. | false |

## Availability

available where FUSE is available

## Examples

```sh
liquid mount /tmp/liquid-mount --read-only
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
