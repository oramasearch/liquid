# `liquid split`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid split <path> <into>
```

## Description

Create a standalone repository from a directory or nested repository, copying all referenced data into its own store and retaining original signed history and object identities. Historical snapshots keep their original paths. The destination must not exist; failures remove incomplete output.

## Options

This command has no command-specific options.

## Availability

available

## Examples

```sh
liquid split src ../src-repository
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
