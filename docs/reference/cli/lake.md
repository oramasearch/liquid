# `liquid lake`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid lake <add|list|use|remove|login|logout|check> ...
```

## Description

Name the lakes liquid works with and choose one per repository. `lake add <name> <url>` names a lake; `lake list` shows them, where each token comes from and the repository's lake; `lake use <name> [<repository>]` records the lake and the repository on it; `lake remove <name>` forgets a lake and its stored token; `lake login <name>` stores a token read from standard input in the operating system's credential store; `lake logout <name>` removes it; `lake check [<name>]` reads the lake's version and says whether this liquid works with it. There is no built-in lake.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--json` | — | Write stable JSON instead of text, for list and check. | false |

## Availability

available

## Examples

```sh
liquid lake add dev https://lake.example.invalid
printf '%s\n' "$TOKEN" | liquid lake login dev
liquid lake use dev 0b6c2f
liquid lake check dev
```

## Exit status

0 on success, 1 when an operation fails or `check` finds an unsupported lake, and 2 for invalid usage.
