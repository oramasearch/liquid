# `liquid drive`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid drive <sync <folder> <remote> [--watch]|status [folder]>
```

## Description

Synchronize a local folder with a drive remote or report synchronization state.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--watch` | — | Continue synchronizing after the first successful transfer. | false |

## Availability

available

## Examples

```sh
liquid drive sync ./documents https://example.invalid/drive --watch
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
