# `liquid install`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid install <package|install-tree> --root <dir> | install --list --root <dir>
```

## Description

Stage a projected tree, apply its declarative intents, and atomically select it.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--root` | `<dir>` | Select the generation root. | required |
| `--list` | — | List complete generations instead of installing. | false |

## Availability

available

## Examples

```sh
liquid install example.deb --root /srv/example
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
