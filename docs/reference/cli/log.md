# `liquid log`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid log [--ops] [--json] | log timestamps <log-url> | log verify --timestamps
```

## Description

Show named changes or the signed drips and operation metadata that produced them.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--ops` | — | Show signed drips and operation metadata. | false |
| `--json` | — | Write stable JSON instead of text. | false |
| `--timestamps` | — | Verify timestamp evidence after the verify subcommand. | false |

## Availability

available

## Examples

```sh
liquid log --ops --json
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
