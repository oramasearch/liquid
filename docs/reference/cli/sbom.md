## Synopsis

```text

```

## Description

Verify and print a graph-derived SBOM or clearly label local binary inference.

## Options

|---|---|---|---|
| `--spdx` | — | Write an SPDX 2.3 document. | false |
| `--cyclonedx` | — | Write a CycloneDX 1.5 document. | false |
