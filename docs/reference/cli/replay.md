# `liquid replay`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid replay <action|result> [--json] [--record]
```

## Description

Reconstruct a recorded action, compare every result byte, and optionally record verification.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--json` | — | Write stable JSON instead of text. | false |
| `--record` | — | Record the run as a verification sample. | false |

## Availability

available on Linux with FUSE and on macOS with macFUSE

## Examples

```sh
liquid replay blake3:<result-digest> --json
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
