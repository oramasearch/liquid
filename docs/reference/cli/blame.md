# `liquid blame`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid blame <path> [--json]
```

## Description

Show per-line operation attribution for a path at the current change.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--json` | — | Write stable JSON instead of text. | false |

## Availability

available on macOS and Linux

## Examples

```sh
liquid blame src/main.cpp --json
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
