# `liquid data`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid data branch <database> [--session <id>] | data list [--json] | data <discard|promote> <id>
```

## Description

Create, list, discard, or promote PostgreSQL branches bound to repository sessions.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--session` | `<id>` | Select the session to branch for an application database. | new session |
| `--json` | — | Write stable JSON instead of text. | false |

## Availability

available with PostgreSQL client tools

## Examples

```sh
liquid data branch application --session 0123456789abcdef0123456789abcdef
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
