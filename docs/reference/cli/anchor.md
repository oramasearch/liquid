# `liquid anchor`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid anchor <path>:<line>@<change> --to <change>
```

## Description

Follow a one-based text position through edits, moves, replacements, and deletion.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--to` | `<change>` | Select the target change. | none |

## Availability

available

## Examples

```sh
liquid anchor src/main.cpp:42@blake3:<old> --to blake3:<new>
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
