# `liquid write`

> Generated by `liquid docs`; edit the typed command table instead of this page.

## Synopsis

```text
liquid write <path> --from <file> --base <change>[@<cursor>] [--depends-on <path>]... [--on-stale refuse|disjoint|force]
```

## Description

Write a file while recording the exact repository state used to plan the edit.

## Options

| Flag | Argument | Description | Default |
|---|---|---|---|
| `--from` | `<file>` | Read the new content from this file. | none |
| `--base` | `<change>[@<cursor>]` | State the change and optional journal cursor read by the caller. | none |
| `--depends-on` | `<path>` | Add a path read while planning; repeatable. | none |
| `--on-stale` | `<policy>` | Choose refuse, disjoint, or force stale-write handling. | refuse |

## Availability

available

## Examples

```sh
liquid write notes.txt --from /tmp/notes.txt --base blake3:<change>
```

## Exit status

0 on success, 1 on an operation failure, and 2 for invalid usage.
