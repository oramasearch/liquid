# Generated REAPI fixtures

Every `.bin` file in this directory is emitted by Python's official protobuf runtime from classes
generated by `protoc`. `MANIFEST` records the fully-qualified source message for each fixture and
`VERSION` pins the Remote APIs and googleapis revisions plus the protobuf runtime. The Digest
fixture contains an unknown varint field that is parsed and re-serialized by the reference runtime
before it is committed.

Regenerate from the repository root:

```sh
docker build -t liquid-reapi-fixtures tests/reapi
docker run --rm -v "$PWD/tests/reapi/fixtures:/out" liquid-reapi-fixtures /out
```

`directory-reference.bin` and its child are deterministic `Directory` messages for the file tree
described in `docs/library/reapi-codec.md`. `directory-reference.sha256` is the reference SHA-256
digest of the root message bytes.
